# IBM Bob 来参加 coding agent 派对了，背上扛着一台大型机

> 来源 / Source: https://clauday.com/zh/article/10fc881d-f2e2-49b2-974d-72a39d4d5b63

IBM 这个周末把 Bob 推上了 Hacker News（https://bob.ibm.com，325 分，评论区几乎一样长）。产品定位是 agent 化开发伙伴：专注的 agent 和 subagent 并行工作，各带自己的上下文和工具，入口有 IDE、一个叫 Bob Shell 的命令行，还有 CI/CD 流水线。"Literate coding"让你直接在编辑器里用自然语言跟它说话，不用切到聊天窗口。

这些在 2026 年 9 月没有一样是差异化——subagent 和 CLI 集成早就是标配。Bob 真正的差异化是它驮的货：为 Java 现代化、大型机和 IBM i 开发专门打造的套件。其他所有 coding agent 都在抢全新的 TypeScript 项目，IBM 瞄准的是比维护它们的工程师年龄还大的代码库，客户是本来就每年给 IBM 开八位数支票的企业。这是一条真护城河，而且别人根本不想来挖。

第二个值得注意的选择是 Bobalytics：一个在企业范围内追踪 agent 贡献和业务影响的层。别人卖 agent 生产力靠的是感觉和精选 demo，IBM 直接把 CFO 要的仪表盘做出来了。在企业开始追问 coding agent 的钱到底买到了什么的这个季度，这叫读懂了空气。

最扎眼的沉默：只字不提底层用什么模型——在一个所有对手都把模型阵容挂嘴边的季节。免费试用已开放。Bob 好不好用还没被证明；但 IBM 挑了市场里哪个角落去当一个平庸产品——这一步看起来是聪明的。
