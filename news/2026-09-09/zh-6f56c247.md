# OpenAI 的插件市场正在悄悄被厂商填满

> 来源 / Source: https://clauday.com/zh/article/6f56c247-8858-41d3-970d-4b2fdded60dc

openai/plugins 昨天涨了 505 颗星，总数到 6161。对一个内容基本都是 JSON 的仓库来说，这个轨迹挺怪。它装的是 Codex 插件的分发格式，外加一份精选市场清单，而这份清单一直在稳定地攒名字：Qodo 周一进来，CrowdStrike 的 Foundry 和 Fusion 上月底进来，旁边还有 Figma、Notion、Netlify、Expo、Remotion、Google Slides。

真正的新闻是这个格式的形状。一个插件就是一个目录，必需的是 .codex-plugin/plugin.json 清单，其余都是可选：skills、一个 .mcp.json、一个 .app.json、插件级的 agent 和命令、hooks.json，以及素材。看着这份清单，整合就摆在眼前了。几个月前，skill、MCP server、斜杠命令、hook 还是四个各自独立的生态，各有各的仓库、各有各的爆红周。现在它们是同一个可安装单元里的四个可选文件夹。

这比任何单个插件都重要，因为它用发布结束了一场争论。OpenAI 六月把独立的 skills 仓库标记为废弃，当时不少人读成 skills 这条路输了。并没有输，skills 只是从一种格式降级成了一个字段。分发单元现在是插件，而精选发生在 .agents/plugins/marketplace.json 这个文件里，旁边还另有一份 API key 市场清单。

于是有意思的问题不再是 skills 会不会赢，而是货架归谁管。社区的 skill 仓库连着好几个月霸占 GitHub trending（https://clauday.com/zh/article/0c470666-306a-4aea-9833-c53a95254dd2），厂商则在安静地排队，等着挤进一个由某一家公司来合并 PR 的 JSON 文件。https://github.com/openai/plugins
