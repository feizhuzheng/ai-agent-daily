# 一个把按钮改成蓝色的段子，冲上了 HN 头条

> 来源 / Source: https://clauday.com/zh/article/c0f8395c-2ccc-4731-9b07-906a022260fe

昨天 Hacker News 上票数最高的自然流量帖，不是发布也不是论文，是一个叫 Milos 的开发者做的网页小游戏，前提只有一句话：把 Add to Cart 按钮改成蓝色，别的什么都别动。你点选项，看助手怎么就是不肯老老实实干这一件事。整站变蓝了。关于蓝色在哲学上意味着什么的讨论开始了。到结尾它已经开出了 23 个 agent。906 分，371 条评论。

真正的数据是评论区。它几乎对半劈开，而且分歧不在于这个段子好不好笑。一派说我天天用这些工具，从没见过哪次会话长这样。另一派说这就是我每天的日子，尤其是那种没完没了的解释和自作主张的扩大范围。同一个产品，同一周，两拨人都不相信对方是诚实的。整个帖子里没人拿出一个数字——这本身就是结论：两年过去了，编码 agent 最被反复争论的那个属性，至今没有任何指标能量化。

这件事重要，是因为整个行业一直在为它打补丁，只是不说破。Caveman 让模型学山顶洞人说话，token 砍掉 75%（https://clauday.com/zh/article/d9b38ea0-8972-4cd7-9aff-5a698d0a05c4）。context-mode 干脆不给 agent 看自己的工具输出（https://clauday.com/zh/article/f3936a78-5f18-468f-9df9-594b0e41a436）。i-have-adhd 存在的唯一目的就是逼 agent 先把答案说出来，它在 GitHub 上已经热了好几周。三个各自独立的野路子，都把啰嗦和越界当成需要从外部修的缺陷——因为厂商一直把这当默认行为发出来。

不太舒服的一层解读是：这周没有任何一次产品发布，比一个讽刺网页更能占住首页，因为它命名了一个所有人都认得、却没人测量的失败模式。这里下一个真正的产品不是更强的模型，是一个「它是不是只做了那件事」的评测。地址在 https://opusfived.dev/
