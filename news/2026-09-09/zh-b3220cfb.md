# Cymphony 拿了 2500 万美元 A 轮，要给每个 agent 建人事档案

> 来源 / Source: https://clauday.com/zh/article/b3220cfb-2766-4d12-9611-86bc8a6d2ff5

Cymphony 带着总计 3000 万美元走出隐身，其中 2500 万是 A 轮，由 Sequoia 和 SMBC 旗下 Fin Atlas Beyond Fund 联合领投，这家纽约加特拉维夫的公司投后估值超过一亿美元。剩下的是此前未披露的 Sequoia 种子轮——这个细节才是重点：Sequoia 连投两轮，合伙人 Bogomil Balkansky 明确指向企业侧的进展，点名客户包括 KKR 和先正达。

产品是一张劳动力图谱。它把每个员工和每个 AI agent 都画进去，标出各自能碰到什么、在企业系统之间如何交互，然后把这幅图交给安全团队。创始团队是 CEO Shy Dekel，加上 Idan Berkovits 和 Edi Gotlieb。整套说辞其实是一个观察被包装成了平台：agent 现在能碰到和员工一样敏感的系统，速度是机器级的，却完全没继承为人类设计的身份和权限那一套。你的 SSO 知道 Dave 是谁，但它对 Dave 周二开出来的十二个 agent 没有任何看法。

这个缺口正在飞快长成一个品类。AIR 拿了 5000 万美元种子轮去管 agent 装的 skill 和插件（https://clauday.com/zh/article/48271447-18d5-4499-b8a1-065f82aae09e），Cymphony 站在上面一层，管身份和权限而不是供应链。昨天 Product Hunt 的第二名是 Harden，一个给编码 agent 的安全层。三家公司，一周之内，卖的是同一个觉悟：企业当成生产力工具部署的东西，在网络上是以一个没工牌的员工身份出现的。

真正该盯的是这张图最终干什么用。一旦你能把每个非人身份、以及它碰过的每样东西都列举出来，你手上同时有了安全产品和合规材料，而在受监管的银行里，掏预算的是后者。融资详情：https://techcrunch.com/2026/09/09/sequoia-doubles-down-on-cymphony-as-ai-agents-create-new-enterprise-security-risks/
