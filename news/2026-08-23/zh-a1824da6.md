# free-claude-code：绕开前沿模型的民间版本

来源 / Source: https://clauday.com/zh/article/a1824da6-bf46-4957-b52b-ca50279eaaa1

FT 在记录企业如何从昂贵模型分流，而一个叫 free-claude-code 的仓库正在给个人干同样的事，而且在 GitHub trending 上冲得很快，一天涨了一千多星，逼近 48k。它的卖点很直白：用它号称的每月 13 亿免费 token，去跑 Claude Code、Codex、Pi、OpenCode 这些编码 agent，靠的是把 49 家不同的模型供应商缝在一起。

它不是破解，也不绕任何付费墙。它是一层代理，用你自己的 key，把请求分发到 NVIDIA NIM、Groq、OpenRouter 这些供应商的免费和试用额度上，一家用干了自动切下一家。它还能把终端输出砍掉最多 90% 来省 token，能做语音转写，能接进 VS Code、JetBrains、Discord、Telegram，也能通过 Ollama 和 LM Studio 跑本地模型。维护者说他们遵守各供应商条款，谁不让用了就把对应集成撤掉——对一个完全靠别人免费额度活着的工具来说，这算是诚实的说法。

它该跟 Fable 和 Ox Alpha 那两条放在一起，是因为这是同一种本能在市场底层的表达。企业造路由器去套 token 差价。个人装 free-claude-code，手动在能找到的每一份免费额度之间套。两边押的都是同一注：该拥有的是 harness 和路由，不是某个具体模型。前沿一贵，长尾就是这么应对的。仓库在 github.com/Alishahryar1/free-claude-code。
