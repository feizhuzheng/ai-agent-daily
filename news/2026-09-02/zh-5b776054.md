# Humanizer：一个专门删 AI 味的 skill，四万星

> 来源 / Source: https://clauday.com/zh/article/5b776054-f3dc-4ab2-98c4-e33721b2a55d

Humanizer 是个只干一件事的 agent skill：把 AI 生成的文字改写到不像 AI 写的。四万多星，今天又涨 366——而它在结构上就是一个 Markdown 文件。作者 blader（Siqi Chen），MIT 协议，能通过 Skills CLI、Claude Code 插件市场或 Claude Desktop 安装。

方法论是值得研究的部分。它把维基百科"AI 写作特征"清单编码成 35 条模式——破折号成瘾、"这不是 X，而是 Y"、以"总的来说"开头的总结段——然后跑多轮：先不把原文结构当圣旨地重写，再拿草稿对照模式清单和原文事实核查，然后再改一遍。不编造细节，代码和链接不动，喂它你的写作样本还能学你的语气。

维基百科编辑花三年整理 AI 特征清单是为了识别 AI。Humanizer 把这份清单反过来用成了文风指南——检测清单和规避工具现在是同一份文档，四万人给规避那一面点了星。它同时也是 skills 论题迄今最干净的演示：原本长在某个人脑子里的写作判断力，被打包成一个任何 agent 都能执行的文件。这一个文件的星数超过大多数框架。

仓库：https://github.com/blader/humanizer
