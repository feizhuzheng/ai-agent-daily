# Muse Spark 1.3：Meta 学会不浪费 token 了

> 来源 / Source: https://clauday.com/zh/article/a76f0fe6-3480-48ee-bb9c-7da1a3880836

Meta 9 月 2 日发布 Muse Spark 1.3，自称是迄今在编码和 agent 能力上最大的一次跃升。已经上线 Muse Code 和 API，接下来推到 Instagram、Facebook 和 Meta AI，价格和 1.2 一样。Alexandr Wang 对 Axios 说这版让 Meta 接近 GPT-5.6 级别；Zuckerberg 说开源权重版本在路上。

Meta 选择领跑的那个数字很说明问题：同样的活，1.3 比 1.2 少用大约 20% 的工具调用、25% 的 token。不是更聪明，是跑起来更便宜。当 lab 们开始宣传单任务效率而不是 benchmark 涨了几个点，说明买家变了——这是说给按预算跑 agent 集群的人听的，不是说给看排行榜的人听的。同一天的背景：Anthropic 刚把缓存读取降价 75%，Google 发了促销价的 Flash。三家前沿 lab 突然都在卷同一件事：一个 agent 循环跑一圈要花多少钱。

在更多长程编码任务上训练，价格不变，承诺开源权重。春天 Meta 还在因为 Muse 交易反悔的烂摊子被嘲，两个小版本之后这条线在 agent 任务上真有竞争力了。HN 上发布帖 250 多分。
