# AIR 种子轮 5000 万美元：给 agent 技能供应链装防火墙

> 来源 / Source: https://clauday.com/zh/article/48271447-18d5-4499-b8a1-065f82aae09e

AIR 9 月 1 日结束隐身，宣布 5000 万美元种子轮，Sequoia 和 Greenoaks 联合领投，Swish Ventures 跟投——分两笔快速完成，先 1000 万再 4000 万。创始人 Yair Saban（CEO）和 Niv Hoffman（CTO）都出自以色列 8200 部队。产品逻辑：发现公司内部跑着的每一个 agent，持续审查这些 agent 用的技能和插件，拦掉过不了安全检查的。再加一个预审认证的插件市场——一个把审核流程本身当产品卖的应用商店。

他们的扫描数据解释了 Sequoia 为什么出手。超过 17,800 个公开 agent 插件、合计 670 万次安装，从没人验证过的外部源拉取指令。他们还发现了冒充 Anthropic 和 OpenAI 的技能，装上就能执行任意代码。他们的系统目前把评估对象里的大约 27% 拒之门外。粗算下来，每四个公开 agent 技能就有一个过不了基本安全线——这就是企业今天正在往里装的供应链。

时机好得不用解释。Skills 两个月内从 Claude Code 的一个功能变成了跨厂商的打包标准，而包注册表的规律从来如此：采用速度一超过审查速度，安全产业就来了——npm 等来了 Snyk，agent skills 现在等来了 AIR。隐身期结束直接 5000 万种子轮，说明投资人认为"可信层"这个位置的窗口就是现在，得赶在某家 lab 把它做成内置功能之前。
