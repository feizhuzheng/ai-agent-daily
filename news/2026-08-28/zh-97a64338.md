来源 / Source: https://clauday.com/zh/article/97a64338-f87f-492b-964d-f6284f01936c

用户心声

当天最响亮的需求来自 @TonyXavier_：他愿意"付一笔离谱的钱"换一个能同时看到 Claude Code、Codex、Cursor 所有 agent 的桌面应用——几小时内评论区就有厂商来应征。多 agent 驾驶舱已经是这个生态里被点名最多的产品。

紧随其后的是换工具不丢记忆。@Gencoin8 描述了每次会话额度用尽、从 Claude Code 切到 Codex 时,三个小时积累的决策全部清零的痛苦;而 Memmy 这类跨 agent 记忆层的出现,把"为什么换个工具我的 AI 就失忆"变成了本周的标志性抱怨。

额度和成本仍是一道敞开的伤口,而且两头都有人在喊:@PatrickChareyre 每周打满四个 200 美元的 Claude Max 套餐,自称已经管不住这个瘾;@JayHhdmg 二十分钟烧穿 Codex 五小时额度后回头感叹 Claude 大方;@fentasyl 却反向退订,声称 Codex 给了二十倍用量。把 34 家平台免费额度串成一个接口的路由器爆火,就是这道伤口的直接症状。

信任与验证正在悄悄长成一个独立品类:@kohya_tech 不敢开 auto mode,因为 Claude 会乱翻他磁盘的奇怪角落;@wunderwuzzi23 的全链条入侵演示证明这种直觉值多少钱。验证 Skill 和权限工具会是下一波淘金地。

物理世界的前线正式打开:@lydiahallie 在征集固件、机器人、家庭自动化的用户案例,Anthropic 的 MHS 预览把 Claude 放上了实验室设备,业余玩家已经在烧录 ESP32。"改文件的 agent"和"动物质的 agent"之间的距离,这一周肉眼可见地缩短了。
