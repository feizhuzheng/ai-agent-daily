# freellmapi：34 家免费额度，缝成每月 74 亿 token

来源 / Source: https://clauday.com/zh/article/91e2ca93-8a67-4fff-b925-a8d8d6d989dc

"绕开昂贵前沿模型"运动又添了一件基础设施。freellmapi 正在 GitHub 趋势榜上，21.6k 星，把 34 家 LLM 提供商的免费额度——Google、Groq、Mistral、OpenRouter、Cohere 等等——聚合成一个 OpenAI 兼容端点：635 个免费模型端点，全部用满约等于每月 74 亿 token。仓库在 https://github.com/tashfeenahmed/freellmapi。

它比常见的"倒腾 key 的脚本"工程化得多：智能路由按速度和可靠性评分选模型，请求失败自动切换供应商重试并带冷却机制，逐 key 用量追踪保证不超各家免费配额，密钥 AES 加密存在 SQLite，还有管理面板、playground 和 Claude Code 接入。维护者对它是什么出奇地诚实：供个人实验和学习，不是生产用——免费额度没有 SLA，不是稳定的推理基座。

重要的是模式。free-claude-code 在 49 家供应商之间套利 token 层级，sub2api 把订阅转成 API，现在这个项目把免费额度公地正式化成了一块总电表。每家供应商的营销预算——免费额度——正被开源中间件汇成一个事实上的全球免费推理层。供应商要么收紧配额，要么接受免费额度已经变成公共事业。这条线的前情：https://clauday.com/article/ecc6355d-5bc1-4051-a96b-b9fd4d7428f9。
