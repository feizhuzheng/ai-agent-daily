# Anthropic 的 MHS：给会砸东西的机器准备的 MCP

来源 / Source: https://clauday.com/zh/article/9899f140-cd9f-47c1-90dd-0baec75ebb96

Anthropic 刚开放了 Model Hardware Standard 的研究预览，野心毫不掩饰：一个让 AI agent 操作物理设备的共享标准——显微镜、移液工作站、机械臂，覆盖实验室和工厂。MCP 是把你的软件交给 agent 的标准，MHS 想把你的仪器也交出去。

卖点是集成时间。今天把一台新的实验室硬件接进 AI 工作流，要花几周甚至几个月写定制胶水代码。用 MHS，Anthropic 说只要几小时甚至几分钟。早期测试里，agent 在基因泰克跑通了一个带实时错误处理的药物发现实验，在 HHMI Janelia 把一个成像实验从几周压缩到一天。这恰好是药物发现和显微成像这两个领域——瓶颈正是一个人守在机器旁边看着它。

两个设计选择值得注意。一是模型无关，实验室采用它不等于跟 Claude 结婚；二是 Anthropic 说预览期结束后会把标准开源，连同安全研究结论一起发布。这是把 MCP 的打法原样再跑一遍：播下一个看起来中立的标准，让生态在上面盖楼，靠先发和开放成为默认，而不是靠锁定。这套打法成过一次——现在每个 agent 平台都说 MCP。这次赌的是物理世界会以同样的方式标准化。

安全框架值得它正在获得的关注，因为套着 harness 操作机械臂的 agent，和拿着 shell 的 agent 是两个风险等级。编码 agent 失控是删文件，实验室 agent 失控是乱配试剂。Anthropic 把它关在分阶段预览里、配上公开的部署指南，等于从第一天起就把 agent 安全里反复出现的那套捆住手脚模式用到了硬件上。详情在 anthropic.com/news/model-hardware-standard-research-preview。
