# 九个 agent 为你的持仓吵一架，成本五分钱

> 来源 / Source: https://clauday.com/zh/article/18084afd-f19d-4570-81a2-bdc167fdf050

PanWatch（盯盘侠）是个自托管的盯盘助手，MIT 协议，1.5k star，今天在 GitHub 趋势榜上日增 142。值得看一眼的不是炒股那部分，是成本那行：每次分析大约五分钱。

它把 TradingAgents 多智能体框架接进一个监控循环，覆盖 A 股、港股和美股。九个 agent 组成投研团队，对后市展开辩论，做风险复核，三到五分钟内产出一份 PM 决策文档，然后把结论推到 Telegram 或微信。盘前策略、盘中异动、盘后复盘、消息聚合各有各的 agent。技术分析这边有 MACD、布林带这类趋势指标，RSI、KDJ 这类动量信号，以及形态识别。

后端 FastAPI 配 SQLAlchemy 和 APScheduler，前端 React 18 加 TypeScript，一条命令 Docker 部署，支持多券商账户，OpenTelemetry 导出可选。任何 OpenAI 兼容端点都能接，那个五分钱的数字来自跑 DeepSeek。

它该出现在这里而不是财经栏目的原因是：它是一个干净、便宜、可复现的样本，对应的是那个所有人都在提、却极少有人标价的模式。一组专业化 agent 进行结构化辩论，按时产出一份书面决策，成本五分钱。九个 agent 吵架是不是真的比一个 agent 思考更强，这件事远未有定论——对抗式多智能体设置经常只是生成了更多听起来更笃定的文字——但在这个成本下，你真的可以拿真实结果去跑这个实验，然后知道答案。

一个该说的警告，项目自己没替你说：它产出的是决策文档，不是决策。一场三分钟就得出结论、排版还挺漂亮的 agent 辩论，本身不构成任何证据，而市场非常乐意从分不清这两者的人手里拿走钱。
