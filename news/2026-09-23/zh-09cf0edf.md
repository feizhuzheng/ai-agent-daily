# Claude 发现了一套新酶系统，基因编辑股当天就跌了

> 来源 / Source: https://clauday.com/zh/article/09cf0edf-3466-416f-bd97-e2a69340c024

950 个 agent。21 小时。2.1 亿 token。换来一套此前没人描述过的酶系统。

Anthropic 把 Claude 扔进一个巨大的 DNA 序列数据库，基本只给了一句指令，然后就不管了。他们对自己参与程度的说法很直白：提示词是人写的，湿实验是人做的，中间全是 agent。大约 950 个 agent 梳了 21 小时序列之后，其中一个停在一段不寻常的逆转录酶上，注意到旁边还杵着个东西——一列间隔均匀的串联重复序列，也就是 CRISPR 的结构签名。那个 agent 自己的记录读起来就像真人愣住了：这是 CRISPR 式的重复阵列？！

找到的东西现在叫 ART，array-associated reverse transcriptases。三个部件：逆转录酶本身，旁边一个功能未知的搭档基因，再加上那列间隔均匀的长重复阵列。主要出现在噬菌体里，也就是感染细菌的病毒。逆转录酶家族本身不新，新的是这套系统。此前的工作抓到了酶，漏掉了阵列和辅助蛋白，而恰恰是这两样让它看起来可编程。

Anthropic 自家的实验室随后在实验菌株里表达了这个蛋白，发现那列阵列会被转录成一组各不相同的短 RNA。这才是要害。短的导向型 RNA 加一个酶，是人类做出来的每一件可编程生物学工具的形状。Feng Zhang 审阅了结果并给了背书，这世界上有资格判断这件事的人不多，他是其中之一。预印本叫《Autonomous AI agents discover reverse transcriptases with tandem repeat arrays》，未经同行评审。

市场的反应自己讲了个故事：消息出来当天基因编辑股下滑。那是投资人在给一种可能性定价——这个领域的发现瓶颈从来不是测序能力也不是实验室吞吐，而是有多少受过训练的眼睛能把所有东西都看一遍。950 个 agent 看 21 小时，这个注意力的量，没有哪个实验室买得到。

该说的保留 Anthropic 自己也说了：预印本，未经评审，生物学功能仍然未知。目前没人证明 ART 能干什么有用的事。但流程上的主张和生物学上的主张是可以分开看的，而且前者更大。一群 agent 读了个数据库，注意到一个结构，湿实验确认这个结构真的存在。不管 ART 最后被证明是干什么的，这个闭环跑通了。
