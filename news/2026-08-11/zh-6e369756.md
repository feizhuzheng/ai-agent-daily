# Paperclip 给你的 agent 发组织架构图和预算

Source: https://clauday.com/zh/article/6e369756-cd42-46fa-9bf0-fe858c0b7d05

今天 GitHub 上涨得很凶，+743，累计 77.1k star、14.2k fork。Paperclip 自称是「大家用来管理干活 agent 的那个 app」，这个定位刻意做得很无聊：它是控制面，不是聊天框。你定义业务要达成什么，给 agent 分配角色，然后在一个面板上同时盯着活和钱。

功能列表读起来像 HR 加财务系统，而这正是它的意思。任务管理。组织架构图。预算强制。治理控制。执行监控。它能驱动 Claude Code、Codex 以及你自己接的 agent，所以它不跟你的 harness 抢位置——它坐在上面，决定哪个 harness 接哪个活、干这个活最多允许花多少钱。

MIT 协议，TypeScript + Node，前端 React，master 上 3545 个 commit。同时还有 2100 个 open issue，这两个数放一起说明两件事：用的人是真多，项目也是真年轻、跑得真快。别周五下午上生产。

这已经是上周从 T3 Code 和 OpenChamber 开始那条线上的第三个了。现在没人在拼「做一个更强的 agent」，大家都在抢那一层：告诉一队 agent 该干什么，并且拦住它们一夜烧掉一万美金。把预算强制当成头号卖点写出来，这就是信号。一年前有意思的问题是 agent 能不能把活干完。现在有意思的问题是花了多少钱、谁批的。
