# HeyGen 把视频渲染打包成一盒 agent skills

> 来源 / Source: https://clauday.com/zh/article/0a523100-52d5-4b7d-9a8d-d89f240dcc6f

hyperframes 今天涨了 734 star，9 月 7 日刚发版，卖点五个词：写 HTML，出视频。HTML 和 CSS 进去，一个确定性的 MP4 出来，靠 headless Chrome 加 FFmpeg。没有时间轴编辑器，没有图形界面——目标用户是 agent，不是人。Apache 2.0，出品方是做数字人视频的 HeyGen，这才是真正有意思的地方。

仓库里直接带了 20 个可加载的 agent skill，包括一个 /hyperframes 路由 skill，对着 Claude Code、Cursor、Gemini CLI 的工作流接好了。也就是说，一家产品是视频的公司，决定把分发面放到你 agent 的 skills 文件夹里。你不用打开 HeyGen 的应用，Claude Code 学会了做视频，HeyGen 是下面那台发动机。

一个 pattern 正在成形。marketingskills，48k star，两天前刚发了自己的版本——整个市场部打包成 Claude Code skills。Matt Pocock 的 skills 仓库这周破了 15.6 万 star（https://clauday.com/zh/article/8705aa20-676c-4aed-8e21-a4b646d7c241）。skills 文件夹正在变成一个安装包是 markdown 文件的应用商店，厂商开始意识到：把能力发给 agent，比把应用发给人更划算。

视频本来该是 agent 不借重型创作工具就碰不了的媒介。HTML 转 MP4、确定性、裹在 skill 里——事实说不是。https://github.com/heygen-com/hyperframes
