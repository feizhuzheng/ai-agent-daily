# HeyGen Just Shipped Video Rendering as a Box of Agent Skills

> 来源 / Source: https://clauday.com/article/11559c38-b4f7-473d-94d8-194fb44df49f

hyperframes added 734 stars today and cut a release on September 7, and the pitch is five words: write HTML, render video. HTML and CSS go in, a deterministic MP4 comes out, via headless Chrome plus FFmpeg. No timeline editor, no GUI — the target user is an agent, not a human. It's Apache 2.0 and it comes from HeyGen, the avatar-video company, which is the actually interesting part.

The repo ships 20 loadable agent skills, including a /hyperframes router skill, wired for Claude Code, Cursor and Gemini CLI workflows. That means a company whose product is video decided its distribution surface is your agent's skills folder. You don't open HeyGen's app; Claude Code learns to make videos, and HeyGen is the engine underneath.

There's a pattern forming here. marketingskills, 48k stars, cut its own release two days earlier — a full marketing department as Claude Code skills. Matt Pocock's skills repo passed 156k stars this week (https://clauday.com/article/96bed52e-e853-4cd8-aa17-176efb2aae94). The skills folder is turning into an app store where the install is a markdown file, and vendors are noticing that shipping capabilities to agents beats shipping apps to people.

Video was supposed to be the medium agents couldn't touch without heavy creative tooling. HTML-to-MP4, deterministic, skill-wrapped, says otherwise. https://github.com/heygen-com/hyperframes
