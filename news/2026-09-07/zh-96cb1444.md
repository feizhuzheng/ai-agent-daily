# Camofox：网站说不欢迎的时候，agent 用的浏览器

> 来源 / Source: https://clauday.com/zh/article/96cb1444-17e7-4b30-b27b-9065f5e844cb

camofox-browser 今天涨了 285 star。这是一个给 AI agent 用的 headless 浏览器服务，底子是 Camoufox——一个在 C++ 层面内置反检测的 Firefox 分支。不是插件在演戏，是浏览器本身在说谎。上面套了一层为 agent 设计的 REST API：带稳定元素引用的无障碍树快照、搜索宏、token 压缩的页面表示，免得 agent 的上下文被 DOM 汤淹死。MIT 协议。

得说实话：这是军备竞赛的其中一方。网站在自卫式地封锁自动化流量——AI 爬虫一度吃掉 kernel.org 五分之一的算力（https://clauday.com/zh/article/062ce41b-cd38-4fa1-a0aa-f3e903a69db8）——而这类工具的存在就是为了穿过这些防线。同一个能力，既服务想让 agent 在没有 API 的网站上订机票的用户，也服务跑一万个爬虫的运营者。仓库 README 里甚至挂着警告：有加密货币骗局在蹭它的名字发币。这个角落的热度可见一斑。

技术上有意思的是 agent 原生接口这部分。裸 Playwright 给 agent 的是截图和会烂掉的选择器；稳定引用加无障碍树、再压到 token 预算内，才是当消费者是模型时浏览该有的样子——好几个认真做 agent 浏览器的项目都收敛到了这个形态。

互联网正在悄悄裂成两层：欢迎 agent 的走 API，剩下的全是加固过的 GUI。Camofox 是不受欢迎的那些 agent 在过渡期用的东西。https://github.com/jo-inc/camofox-browser
