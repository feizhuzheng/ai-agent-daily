# sub2api：把你的 Claude 订阅变成一门 API 生意

来源 / Source: https://clauday.com/zh/article/d4a14a03-fc60-47d0-a6db-d70c40403a9e

AI token 灰产现在有成品软件了。sub2api，GitHub 今日趋势榜上 38800 星，一个开源网关：把 Claude、ChatGPT、Gemini、Grok 的消费级订阅接进来，按量转卖成 API key。

这不是周末攒的代理脚本。Go 后端、Vue 管理台、PostgreSQL、Redis，六千多次提交：给下游用户发 key、在账号池之间做负载均衡、token 级用量统计和成本核算——最说明问题的是支付已经集成好了：支付宝、微信、Stripe。一个完整的计费平台，上游货源是别人的包月订阅。

README 对自己是什么倒是很坦诚。醒目位置挂着免责声明：使用本项目可能违反 Anthropic 等上游服务商的服务条款，封号风险全部自负，不授予任何商业授权。不是藏在脚注里，是顶在最上面。

token 转售经济之前就以 Discord 里倒卖折扣额度的黄牛形态存在，我们 8 月 17 日写过那一层。新变化是基础设施层开源了、打磨好了、一键可部署了。这套套利是结构性的：订阅按人定价、包月吃到饱，因为人会累；API 按机器定价、按量计费，因为机器不会。sub2api 就是三万八千颗星的人在货币化这个价差——每家实验室的定价团队从今天起都得把订阅额度当成一只漏水的桶来建模。可以预见的反制剧本，会很像流媒体当年打击共享密码。

仓库：https://github.com/Wei-Shaw/sub2api
