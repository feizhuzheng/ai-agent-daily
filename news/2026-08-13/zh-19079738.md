# Gemini 3.7 Flash：三周迭代，价格砍半

> Source: [clauday.com](https://clauday.com/zh/article/19079738-4585-4b7d-bb92-eb0028b96548)

Google 发了 Gemini 3.7 Flash，距离 3.6 Flash 只有三周。三周。到 2026 年底的促销价是每百万输入 0.75 美元、输出 3.75 美元，正好是 3.6 Flash 上线价的一半。一家公司在上一代发布一个月内就把价格砍半，这不叫路线图，这叫纠错。

数字解释了这份急迫。DeepSWE v1.1 从 49.0% 涨到 65.3%。FrontierCode 1.1 Main 从 34.4% 到 43.6%。WebDev Arena 的 Elo 从 1538 到 1588。文档处理在 GDP.pdf 上从 22.0% 跳到 34.0%，对任何拿 agent 处理发票合同的人来说，这一行才是真正改变流程的那行。Google 说这是他们迄今为止最聪明的编码和 agent 主力模型，这次 benchmark 的涨幅确实撑得起这个形容词。

对做 agent 的人来说，定性描述比数字更重要。Google 说这个模型更会应对卡壳，意图真的含糊时会主动问清楚，指令遵循的保真度更高。这三条行为，决定了你的 agent 是自信满满地烧掉四十轮做错事，还是停下来问一句。指令保真度是那种听起来很无聊、但直接决定你 harness 能不能跑通的指标。

还有个背景值得记住：Gemini 3.5 Pro 还在延期。旗舰一再跳票，而 Flash 线保持三周一发的节奏，还一路降价。Google 在用出货量和节奏拿下主力档，同时让前沿档等着。如果你相信 agent 消耗的大部分 token 都是便宜 token，这个策略是自洽的。而 agent 消耗的大部分 token 确实是便宜 token。

现已上线 AI Studio、Vertex、Android Studio，Gemini app 里的 Spark 也在向 AI Pro 和 Ultra 订阅用户推送。
