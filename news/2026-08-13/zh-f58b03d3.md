# DeepSeek Harness：一切皆插件，这句话是认真的

> Source: [clauday.com](https://clauday.com/zh/article/f58b03d3-19d6-481d-a1e7-f1d5795be1c1)

DeepSeek 把自己的 agent harness 开源了，MIT 协议，很多人 README 还没读完，star 已经冲到 3.8 万。项目叫 dsh，TypeScript 写的，距离 V4 Pro 正式版上线只隔了一天。宣传语就四个字：一切皆插件。

这不是营销话术。模型、工具、skill、会话、沙箱、存储、agent 循环本身、调度、UI，全都是插件，改配置就能换，不用碰 harness 源码一行。底座是 Cordis，一个可组合的内核，负责插件依赖，让插件之间通过服务和事件互相调用。自带四种运行模式。Standard 是全套工具。Code 模式让模型直接写 TypeScript 程序去编排好几轮工具调用，而不是一次吐一个调用。Minimal 砍到只剩 bash 和文件编辑器，存在的意义就是让你测模型的时候，harness 不替模型美颜。Creator 用来做自己的预设，带运行时检查。

真正被低估的是会话日志。模型看到的一切都进一个只追加的事件流：system prompt、推理过程、工具调用和返回、子 agent 调度、每一次上下文注入，全部按来源打标。恢复、分叉、搜索、回放，都跑在同一条流上。谁调过第 60 轮突然跑偏的 agent 谁知道，上下文现在就是个黑盒，十几只看不见的手往里塞东西。DeepSeek 把它变成了一个你能打开读的日志文件。

意图很清楚。过去一年的 benchmark 混战教会所有人一件事，harness 和模型一样重要，而好用的 harness 全是闭源的。Claude Code、Codex、Cursor。DeepSeek 的打法是把壳送出去，让换脑子变成改一行配置，这恰好是一家 token 最便宜的模型公司最想生活的世界。Minimal 模式就是马脚，专门做一个模式来公平衡量模型，而他家卖的是最便宜的前沿模型。

开发者预览版，接口会破坏性变更。npx @deepseek-ai/dsh web 就能起本地 web UI，端口 3080。代码在 github.com/deepseek-ai/deepseek-harness，文档在 deepseek.com/harness。
