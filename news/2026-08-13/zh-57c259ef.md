# holaOS 想当 agent 干活的那个房间，不是又一个 agent

> Source: [clauday.com](https://clauday.com/zh/article/57c259ef-b629-4bfc-9e4f-d59015c466f7)

holaOS 今天冲上 GitHub trending，6500 star，有意思的是它拒绝成为什么。它不是又一个 agent。它是一个本地优先的工作区，让 Claude Code、Codex 和它自带的原生 agent 并排跑，共享同一份记忆、工具和集成。

承重的部分是记忆。上下文和项目历史以可编辑文件的形式存在本地，不在谁家云上，而且跨会话、跨 agent 切换都保留。最后半句才是重点。现在你用的每个 agent 都各自失忆，从 Claude Code 换到 Codex 就意味着把项目从头讲一遍。把记忆做成硬盘上一个任何 agent 都能读的文件夹，换 agent 这件事就从一次迁移变成一个日常动作。

其余部分能打但在预期之内：100 多个一键 OAuth 集成，涵盖 Gmail、Slack、GitHub、Linear、Notion，支持 MCP 接自己的工具，可复用的 skill 打包成工作流并跨 agent 部署，内置 Opus 5 和 GPT-5.6 也可以自带 key。超出预期的是 HolaApps，把 Notion、浏览器这类真实界面直接开在 agent 旁边，你是在跟它并肩干活，而不是对着它打字。TypeScript 运行时，Electron 桌面端覆盖 macOS、Windows、Linux，可自托管，还有带 SSO 的企业版。协议是改过的 Apache 2.0，对商业分发加了条件，打算在上面做生意的先把条款读完。

往后退一步看，这是两周内第四次认真冲击驾驶舱这一层：T3 Code、OpenChamber、Paperclip，现在是 holaOS。四支互不相干的团队得出同一个结论——模型这层稳了，容器这层没有——这个信号值得认真对待。holaOS 押的具体方向是反锁定，而它瞄准的事实是：最强的那几个 agent 来自一些非常希望顺便把你的工作区也占了的公司。
