# 今天涨最快的仓库，只是 29 个图表模板

> 来源 / source: [clauday.com](https://clauday.com/zh/article/2626cb5a-581a-4377-b5ed-6e87424033f0) · 2026-08-12

此刻 GitHub trending 第一，一天涨了将近 3000 星、总数 1 万：cathrynlavery/diagram-design，给 Claude Code 用的 29 种编辑级图表类型。不是框架，不是模型。HTML 加 SVG 模板，外加一个 skill 教 agent 什么时候该用哪一种。MIT 许可，84 个 commit。

它解决的问题是每个用编程 agent 的人都撞过、后来基本懒得抱怨的那个。让 agent 画个图，出来的是圆角矩形加箭头——技术上没错，视觉上跟其它所有机器生成的图长得一模一样，放进任何客户看得见的地方都不能用。模型的渲染能力没问题，缺的是品味和一套自己的视觉规范，而这两样都不住在权重里。

覆盖面很宽：架构图、流程图、时序图、状态机、时间线、组织架构、数据可视化，每种都有极简亮色、极简暗色和完整编辑三个变体。它能在大约六十秒内从你的网站上抓颜色和字体，让输出符合你的品牌。能导入 draw.io 和 Mermaid 文件并按这套系统重画。WCAG AA 对比度检查和语义化 SVG 是内建的。可导出 PNG 和 SVG。作为 Claude Code 插件安装，Pi 和 Codex 也各有装法。

值得注意的地方不是图。是一个模板文件夹加一页说明，在这件事上打赢了所有通用画图工具，而且几天拿了一万星。设计判断力原来是可搬运的——你可以把它写下来、当成文件发出去，然后 agent 会照着执行。agent 生态现在最有意思的一层不是更聪明的模型，是有人在把"什么叫做得好"编码成模型读得懂的形式。
