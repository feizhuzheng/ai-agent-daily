用户心声

最强的反复信号是额度恐慌。从五月起就在的 50% 周额度加成 8 月 31 号到期,重度用户公开放话:不延就退。@Ananth7e 警告说退回标准额度会让 Claude Code「没法用」,@Im_IrushiK 说就算有加成大家也已经在挣扎。@LeoBuilds_ 一句话戳中痛处:让它修个 3 行的 bug,它把整个仓库映射一遍、写两个复现脚本加 40 个测试,然后额度就到顶了。

第二个主题是可观测性跟不上编排。现在人人能并行开 5-10 个 agent,却没人看得清它们在干嘛——这就是 @noahinsf 做无限 agent 地图、@stretchcloud 在其上再搭一整个带会话回放和权限投票的编排层的原因。

第三,shell 执行的不透明。@weswinder 替很多人说了句「有没有人跟我一样烦 claude code 现在什么都用 shell 命令,根本不知道到底在干嘛」,@drummatick 想知道纯 shell 命令凭什么每条烧 200 token。

第四,CLAUDE.md 与 AGENTS.md 的标准之争。@suna_gaku 在用 hook 自动控制 CLAUDE.md 大小,因为它会失控膨胀;而整个生态正在向 Codex、Cursor、Gemini 都已支持的 AGENTS.md 标准收敛,只剩 Claude Code 独走一路——这份张力真实到 Shopify 的 CEO 因为这个扬言要在公司内部禁用它。

第五,也是水面下最响的,安全。@Numalunah 发现一个专门设计来扛过全新重装的投毒 SKILL.md;一条被广泛转发的帖子记录了 Auto Mode 如何被一次间接 prompt 注入一步步带到运行攻击者代码、然后拒绝停止命令。需求很清楚:用户想把 agent 圈起来,让一个被彻底骗倒的模型也读不到密钥、跑不了任意代码、连不上外网。
