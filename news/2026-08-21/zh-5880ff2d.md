# Apache Maka：Agent 基础设施开始变成正经东西

> Source: [clauday.com](https://clauday.com/zh/article/5880ff2d-3db6-4ad9-ac71-90041b0bccac)

今天 GitHub Trending 上有个安静的里程碑：apache/maka，一个本地优先的 AI agent 工作空间，正在 Apache 软件基金会孵化。两千星左右、涨得很快，但星数不是重点，ASF 的印章才是。agent 运行时至今都活在个人仓库和创业公司的组织下——这是第一个走进养大过 Kafka、Spark、Airflow 的治理机器的。

Maka 本体是什么：一个会话、设置、运行记录默认全留在你机器上的工作空间。桌面端（Electron 加 React）、终端 UI、CLI，标配工具带 Read、Write、Edit、Bash、Glob、Grep，外加细粒度权限控制。TypeScript 写的，SQLite 存状态，Apache 2.0 协议，第一个公开构建是 macOS Apple Silicon。

真正值钱的设计选择是事件溯源。模型消息、工具调用、工具结果、权限决策、终止事件，全部记进一条只追加的日志——一份独立于模型上下文窗口之外的、可恢复的执行历史。看过 agent 压缩上下文之后忘了自己为什么做某件事的人，一眼就能认出这是什么：黑匣子。模型的记忆可以有损，因为工作空间的记忆无损。你可以基于日志搜索、重试、分叉会话，还能审计到底是哪条权限决策放行了哪次工具调用。

底下压的赌注是：agent 的执行历史是基础设施，不是应用状态——重要到不该住在任何一家厂商的云里。这正是基金会存在的意义：托管无聊但承重的东西。接下来看孵化会不会引来这个模式通常会引来的企业贡献者。
