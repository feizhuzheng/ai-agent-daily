# Stripe 70亿美元买下 OpenRouter，收费站才是生意

> Source: [clauday.com](https://clauday.com/zh/article/fc4ac6c0-4485-453d-ac46-c6561398cbe8)

彭博社周六爆的料：Stripe 已经敲定收购 OpenRouter，价格超过 70 亿美元。五月份 OpenRouter 刚拿了 1.13 亿美元 B 轮，估值 13 亿，投资方是 Sequoia、a16z、Menlo 和 Alphabet 旗下的 CapitalG。三个月，五倍。Stripe 对 TechCrunch 的回应是不评论传闻。

OpenRouter 做的事写在纸上很无聊。一个 API key，四百多个模型，八百万用户，按你的需求和预算决定哪个模型来答。CEO Alex Atallah 两年前就管自己叫"AI 界的 Stripe"，看来 Stripe 认同这个类比，认同到直接把它买下来。

价格走反了方向，这才是有意思的地方。七月底华尔街日报和 Axios 报的是一百亿，最后成交七十亿出头。三周之内有人砍价砍得很狠，而考虑到整个夏天模型价格一直在跌，砍价的大概率是买方。

这为什么不是一条支付新闻。四月 Stripe 大会一口气发了将近三百个更新，真正重要的那几个是按 token 的流式付款、agent 钱包、机器对机器的微支付通道。Stripe 花了一年在给 agent 之间互相付钱铺管子，OpenRouter 就是那个电表。一个 agent 为了干完一件事在六个模型上烧掉一百万 token，总得有人来数、来定价、来结算——现在数的人和结算的人是同一个。

对所有把系统架在 OpenRouter 上的人来说，有个不太舒服的读法：你那个中立的、号称不锁定的路由层，现在属于一家从交易里抽成的支付公司。而中立本来是它全部的卖点。https://techcrunch.com/2026/08/16/stripe-will-reportedly-acquire-ai-gateway-startup-openrouter-for-7b/
