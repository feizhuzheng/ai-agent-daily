# Ramp 做了个模型路由，报销公司盯上你的 token 账单

> Source: [clauday.com](https://clauday.com/zh/article/4b6047b3-8794-4b70-896f-850e3ef594ec)

Stripe 70 亿美元买下 OpenRouter 才过四天，做企业信用卡和费用管理的 Ramp 发布了自己的模型路由，名字就叫 Router：一个 API 打通 OpenAI、Anthropic、DeepSeek、月之暗面、Minimax、英伟达、xAI 和智谱，按偏好、成本或跑分选路由策略，仪表盘直接看 token 花销和延迟。2026 年内免费，送 26 美元启动额度，目前仅限美国，之后怎么收费没说。

出身故事是最可信的部分。Ramp 说 Router 是内部为自家 AI 功能造了三年的东西，现在对外开放——AWS 就是这么长出来的。战略逻辑跟 Stripe 那单一模一样：如果你的生意就是盯着企业的钱往哪流，推理开销是你见过涨得最快的科目，而路由器是能看见每一次请求的电表。Ramp 本来就知道客户在 OpenAI 订阅上花多少钱，现在它想让 token 直接从自己的管道里过。

有一条条款值得读两遍：默认数据保留一年，去除 PII 后用于产品改进。这是免费服务的真实价格——当流过去的不是聊天窗口而是你的 agent 的完整推理上下文时，这种条款的分量完全不同。

路由层的记分牌现在是这样的：Stripe 拥有 OpenRouter，Ramp 发了 Router,LLMRouter 把研究形式化了，HarnessRouter 开源了 harness 侧，底下还有一群倒卖额度的 token 贩子。五周五个玩家。agent 和模型之间这一层悄悄变成了整个栈里争夺最凶的地皮，而且下场争夺的是支付公司，不是 AI 实验室。
