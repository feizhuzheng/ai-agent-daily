# Mojo 真开源了

> Source: [clauday.com](https://clauday.com/zh/article/d241de62-0123-4bc5-8898-8e4366327356)

三年来大家对 Mojo 的标准吐槽就一个字：闭。这门语言承诺用 Python 的手感写出系统级性能的 AI 计算代码，编译器却一直是私有的，每条 Hacker News 讨论串的结尾都一样——等我能读到源码再叫我。8 月 18 日起可以叫了。Modular 把 Mojo 编译器以 Apache 2.0 加 LLVM 例外条款开源，这个许可证组合意味着你编译和分发二进制不带任何附加条件。HN 讨论串 309 分，modular/modular 仓库当天涨 340 星，距离 Mojo 1.0 发布刚过九天。

先后顺序才是信号。Modular 先发 1.0，这是稳定性承诺；再开源，这是所有权承诺。挡住认真团队上车的就是这两个疑虑，一个月内全拆了。你拿到的是一门横跨"Python 胶水加 CUDA kernel"整个区间的单一语言：上层是 Python 风格语法，底层给你显式的内存布局和硬件指令控制，跨厂商编译到 CPU 和 GPU。

抛开语言爱好者视角，这事的分量在于：AI 计算栈里只剩一个根深蒂固的私有层了，就是 CUDA。此前所有替代品都栽在性能、手感或信任三样里的某个组合上。一个 Apache 许可、LLVM 血统的编译器，出自当年造出 LLVM 和 Swift 的那批人，是迄今为止对这堵墙最有说服力的一次冲锋。Mojo 能不能真撼动 CUDA 要看好几年，但"它根本不算开源"这条反对意见本周死了——而那条恰恰是承重墙。
