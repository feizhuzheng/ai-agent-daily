# Maritime 想用一个月一美元帮你托管 agent

> 来源 / Source: https://clauday.com/zh/article/19c2dc06-fe0e-42d7-9b99-5fa7c3e7d37e

做一个 agent 已经真的变简单了。但把它部署好、让它稳定运行、需要时能醒过来、还能扛住一个客户凌晨三点来用——这件事没变简单。Maritime 这个部署平台就是冲着这条缝去的：把你的 OpenClaw、ZeroClaw 或者自定义 agent 指过去，它就在云上跑，你不用碰任何基础设施，起价是每个 agent 每月一美元。

这个定价不是噱头，是从架构里长出来的。每个 agent 跑在自己独立的微型虚拟机里，闲时休眠、按需唤醒，所以你不用为一台一天里大部分时间利用率为零的机器付钱。正是这个休眠-唤醒模式，让它能开出一美元的统一套餐，同时还能让你跑上千个面向客户的 agent、每个都在自己隔离的虚拟机里，而不用背那笔通常会让一大群小 agent 变得不划算的按实例云账单。

有意思的是它落在本周其它几个发布里的位置。Superagent 在你自己的 Mac 上给一个 agent 配台电脑，oMLX 把本地模型跑快，而 Maritime 是同一个问题的云端那头：一旦 agent 便宜到随手能做，真正的产品就是它们运行的那层底座。联合创始人把它讲成消除摩擦、让开发者能快速上线和试错，这是诚实的版本——这是给那些要一次拉起一大堆小 agent、而不是一个大 agent 的人卖铲子的。已经在 Product Hunt 和 maritime.sh 上线。
