# 有人赶在删除之前把 Hugging Face 种子化了

> 来源 / Source: https://clauday.com/zh/article/af22976b-6d44-444b-9dac-b817fb31e19d

Pirate Face 把 Hugging Face 上的开源权重变成带校验和的种子，好让原页面消失的那天模型还活着。站点在 https://pirateface.co/ ，Hacker News 上 367 分，目前列出六十六万九千多个可处理的模型。

有意思的是它的设计。每个模型生成的种子都带一个 web seed 指回 Hugging Face，所以上游文件还在的时候，你等于是在以 Hugging Face 的速度从 Hugging Face 下载，同时悄悄给所有人做种。等上游文件没了，web seed 失效，种子群接着供货，模型被标记为已救援。不需要迁移日，不需要谁在某个时刻拍板决定要归档这个东西。

这件事比一年前重要得多。权重下架的理由有很多：授权纠纷、安全撤回、下架通知，以及最常见的那种——某个实验室重组了，没人再为一个旧 checkpoint 付存储费。这个领域的可复现性现在整个压在一家公司的留存策略上，每一篇写着我们对比了模型 X 的论文，都是一条等着变成死链的引用。

运营方是匿名的。只有一个 X 账号和一句很快支持直接发布的承诺，没有署名团队，你要是打算依赖它，这是必须掂量的风险。反过来说，带校验和的种子本来就不要求你信任运营方，只要求你信任哈希，这恰恰是用这套办法做的全部理由。

名字是挑衅，功能是图书馆。这两样东西在开头往往就是同一个。
