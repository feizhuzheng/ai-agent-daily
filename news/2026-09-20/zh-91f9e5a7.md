# Anthropic 开源了 11 个金融 agent，同一套 skill 还能无人值守跑

> 来源 / Source: https://clauday.com/zh/article/91f9e5a7-745e-4b85-b3f0-e85fb511e5db

anthropics/financial-services 这个仓库现在每天涨 236 星，总数三万五千三，哪怕你这辈子都不会做路演材料，也值得看一眼。它是 Claude for Financial Advisors 的参考实现，那个产品 Anthropic 是 9 月 14 日发的。仓库在 https://github.com/anthropics/financial-services 。

里面装的不是一堆 prompt，是十一个有名有姓的 agent。客户覆盖侧有 Pitch Agent 和会议准备。研究建模侧有市场研究员、财报审阅、模型构建。基金运营侧有估值复核、总账对账、月末结账、报表审计。运营侧有 KYC 筛查。它们被打包成六个垂直插件，覆盖财务分析、投行、股票研究、私募、基金行政和运营，一条 claude plugin install 命令装一个。

比行业本身更重要的是架构细节：同一份系统提示词、同一套 skill，跑在两种完全不同的执行模式下。做 Cowork 插件时由人交互式驱动；走 Claude Managed Agents API 时，同一份定义在后端无人值守地跑。这是第一份认真的厂商产物，明确说 agent 定义可以在交互产品和批处理产品之间搬运。如果这条成立，它干掉的是当下每个企业团队都在交的那笔重复开发税。

护城河在连接器，不在代码。财富端接了 Schwab、BlackRock、Addepar、Envestnet、iCapital、Orion、SS&C Black Diamond、Wealthbox、Wealth.com、Vanguard 和 Zocks，数据端接了 FactSet、标普全球、晨星和伦交所集团。定价是 Cowork 加一个免费插件，大约每人每月七十到一百二十美元。

顶上那段法律声明要读，因为那才是真正的产品边界：这些 agent 只起草供人复核的工作成果，不做投资建议、不执行交易、不承担风险。每一家做垂直 agent 的公司最后都会写出类似的一句话，而这句话落在哪儿，价值就在哪儿到头。
