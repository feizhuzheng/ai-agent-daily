# 有人把一个能碰一千个市场的交易 agent 开源了

> 来源 / Source: https://clauday.com/zh/article/f453c717-076c-4c63-99f2-25b17d95fc9b

CloddsBot 一天涨 299 星到 1589。这个项目的描述是 GitHub Trending 上最刺激还是最吓人的一条，取决于你的风险偏好。一个建在 Claude 上的自主交易 agent，跑在 Polymarket、Kalshi、Betfair、币安、Bybit、Hyperliquid、Solana DEX 和五条 EVM 链上。MIT 协议。在 Solana 的 Colosseum Agent 黑客松上十二天做出来的。

有意思的是架构，不是交易。119 个内置 skill，统一策略引擎背后 118 套策略，接了 21 个消息平台包括 Telegram、Discord 和内置 WebChat。你跟它说话，它去交易。风控管道也是真的：VaR 和 CVaR、熔断、回测、巨鲸追踪、套利发现、跟单。446 次提交，253 个 fork，21 个未关 issue。

当一个领域有一块不留情面的记分牌时，agent 长出来就是这个样子。没人需要争论编程 agent 写的代码好不好，在这儿循环要么赚钱要么不赚，每一个 skill 离一个真实仓位只有一次 API 调用。这也是为什么 skill 数量比策略数量更值得看。119 个 skill 就是 119 种用真钱犯错的方式，预测市场加永续加 DEX 路由，一个业余项目能积累的爆炸半径也就到这儿了。

代码在 https://github.com/alsk1992/CloddsBot

有一句话得说清楚：一个十二天黑客松项目接了一千个市场，那是研究产出，不是你该拿去指着自己存款的产品。它值得读的地方在于，这是极少数奖励信号毫不含糊的完全开源 agent 系统之一，研究 skill 怎么设计，它比任何靠人打分的项目都合适。
