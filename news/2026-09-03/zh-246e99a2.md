# Airtop 对 agent 成本的回答：把 agent 编译掉

> 来源 / Source: https://clauday.com/zh/article/246e99a2-395f-4ca6-8625-819276896bcf

Agent Builder by Airtop 昨天拿了 Product Hunt 日榜第一，247 票，思路反着来，反得漂亮：用对话描述一个工作流，让 agent 想明白一次——然后编译成一个确定性程序，按计划运行，坏了自己修，运行成本只有 LLM agent 的零头。

最后半句才是产品本体。大多数 agent 平台每次执行都要跑模型，等于用前沿模型的 token 价格，把同一个浏览加提取的活干第一万遍。Airtop 的编译步骤把 LLM 当成构建期工具，而不是运行期依赖：模型的判断力只花在想通和修复工作流上，无聊的重复执行交给便宜的确定性代码。自愈是那个安全阀：网站改版、编译出的程序跑挂了，agent 醒过来，重新推导工作流，重新编译。

Airtop 的底子是浏览器自动化——agent 登录、浏览、提数据、接你的工具，全程不需要 API——所以自愈循环有个真实的对手：网页 UI 永无止境的漂移。

这和 caveman 从 token 端、前沿实验室从定价端说的是同一件事，还都挤在同一周：agent 循环的成本就是战场，而最便宜的循环是你根本不用跑的那个。详情在 https://www.airtop.ai/。
