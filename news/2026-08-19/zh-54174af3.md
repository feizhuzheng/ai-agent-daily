# fx：Vercel 发了个 6MB 的编码 agent

> Source: [clauday.com](https://clauday.com/zh/article/54174af3-706a-4d07-baa6-be6bb9462335)

编码 agent 都在朝 IDE 的方向膨胀，Vercel Labs 新开源的 fx 狠狠押了反方向：Zig 写的 6.4MB 二进制，10 微秒冷启动，内存个位数 MB，界面像一个 Unix shell，而不是一个假装成应用的终端。Hacker News 上 143 分，评论区是最近少见的高质量 harness 设计讨论。

设计选择很一致。模型无关：本地模型、网关、直连 API、订阅都能跑。系统提示词极简，因为 token 才是真正的成本中心。支持 WebAssembly 加可插拔网络——这是最不寻常的一条，意味着 fx 能嵌进 Node 系 agent 去不了的地方：沙箱、边缘运行时、别人的产品里。扩展全靠 skill、插件和 MCP，不靠内置功能。Apache-2.0，版本 0.0.3，坦率地标着实验性。

有意思的问题是 Vercel 为什么想要这个东西存在。一个微型、可嵌入、模型无关的 agent 不是 Cursor 的竞品，它是一个原语——像 curl 一样随手扔进部署管线或 web 产品里的那种东西。harness 市场正在裂成两端：一端是重型驾驶舱，另一端是大宗商品组件，fx 是目前商品端最纯粹的表达。

安装一行命令，https://fx.sh 。源码真的读得完——2026 年的 agent harness 里，这本身就算一个功能。
