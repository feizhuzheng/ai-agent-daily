# Munder Difflin：办公室还是那个办公室，员工换成了你的 agent

> Source: [clauday.com](https://clauday.com/zh/article/6eb6a327-5a87-4f91-84cd-3ddea280f488)

多 agent 编排工具一直在重新发明组织架构图，还都装作没有。单日涨 797 星的桌面应用 Munder Difflin 干脆挑明了，直接套上《办公室》的皮：你的 agent CLI——Claude Code、Gemini、Grok，你跑什么都行——变成像素风办公楼层里的员工，头像走到工位，消息在桌子之间飞，一个叫 Michael 的主管 agent（号称你的数字分身）读需求、自己搞定日常件、把真正的决策升级给你。

喜剧皮下面是套挺严肃的架构。每个 agent 是真实的终端进程，有自己的工作目录和身份。协作通过一个本地 git 仓库进行，里面放共享记忆、信箱和黑板——整个协作状态可版本化、可 diff、能用你已有的工具直接检查。markdown 语义记忆层提供跨会话回忆，人类闸门把着花钱和破坏性操作，还内置了带 git 历史和 diff 的 Monaco 编辑器。Electron、React、Pixi.js、xterm.js。代码 MIT，像素素材非商用。

值得偷的点子是"git 当消息总线"。大多数多 agent 框架发明一套协调协议然后请你信任它；这个直接用 commit——两个 agent 对状态有分歧的时候，你去读 log 就行。跟 agent 记忆圈刚得出的结论是同一个洞察：纯文件赢过黑盒存储，只不过这次用在协作上而不是记忆上。

世界需不需要一个管 agent 的 Michael Scott 另说，但几周 2600 星说明组织架构图这个隐喻是成立的。https://github.com/chaitanyagiri/munder-difflin
