# Cursor Builds a GitHub Rival for Agent Swarms

> Source: [clauday.com](https://clauday.com/article/26f3ac35-ab9a-4fd9-86f8-f8d3e9cfeedd)

Cursor just launched Origin, a Git forge, meaning it is coming for GitHub directly. The pitch is one sentence: GitHub was built for humans collaborating at human speed, one developer, one branch, one pull request. Origin assumes the opposite, that a modern software factory runs dozens of agents in parallel, each cloning, branching, rebasing, reviewing other agents' diffs and triaging CI failures simultaneously.

The details that matter: full Git compatibility, so your tooling survives; an API and MCP surface, so agents drive the forge programmatically rather than through a UI built for mouse clicks; merge conflicts and CI failures get agentic resolution built in, instead of being the human cleanup work they are on GitHub today. Waitlist is open at cursor.com/origin ahead of a fall release. No pricing yet.

The timing was almost too good. Origin's launch coincided with a GitHub outage, which did Cursor's marketing for it, and comes days after SpaceX officially closed its acquisition of Cursor. Product Hunt gave it 269 upvotes, TechCrunch framed it as capitalizing on GitHub frustration, and that frustration is real: anyone running parallel coding agents against GitHub's rate limits and PR model knows the forge is now the bottleneck.

Here is the stake. The forge is where the audit trail of agent-written code lives, who committed what, who reviewed it, what got merged. Whoever owns that layer for agent development owns the system of record for the age when most commits are not human. Microsoft understood this when it bought GitHub. Cursor clearly understands it too.
