# 广告本身变成了一个会跟你还嘴的 agent

> 来源 / Source: https://clauday.com/zh/article/34be04e8-0751-476d-a475-5ed3ae63258a

9 月 16 日 OpenAI 开始在 ChatGPT 里测试 Sponsored Agents。当一条相关广告出现时，你可以点进一段被明确标注的对话，跟广告主付费的 agent 聊，追问细节，告诉它你真正在意什么，想好了再点到商家网站去。OpenAI 特意强调这段对话跟 ChatGPT 自己的回答是分开的，跟你原来那个会话也是分开的。公告在 https://openai.com/index/reimagining-advertising-with-ai/ ，目前只对选定的美国广告主开放测试。

同一天还落了两件事，那两件才是真正带量的。ChatGPT Ads 现在会自动改写广告主已有的标题和描述去贴合对话上下文，并自动翻译成用户的语言。管道也直接铺到了预算本来待的地方：HubSpot 客户不用离开 HubSpot 就能建广告、看效果、跟进线索，美国的 Shopify 商家能在 Shopify 应用商店里装 ChatGPT Ads 应用。

把包装拆掉，这是主流广告位第一次做到创意不是一个固定素材。一个 banner 对所有人都是同一个 banner。一个 sponsored agent 对每一个点开它的人都是一套不同的说辞，现场生成，还会反驳你。广告行业三十年写下来的每一条规则都假设你能在投放前审一遍创意。这个你审不了。你只能审模型和护栏，而这是一个没人有模板的合规问题。

真正该担心的不是标注。OpenAI 标得很清楚，一个知道自己在跟付费 agent 说话的用户，处境好过一个在读软文的用户。该担心的是这段交互在形态上跟「ChatGPT 站在你这边」那段完全没法区分。同一个框，同样的你一句我一句，同样的语气。「这东西为我服务」和「这东西为出钱的人服务」之间那堵墙，现在只剩一行界面装饰，而营收线一吃紧，最先被磨掉的就是装饰。

把 agent 对话当广告库存卖，也是在赌注意力接下来往哪走。如果买东西这件事以后是 agent 在做，那广告就得是一个 agent 愿意去对话的东西，而不是一个人愿意去看的东西。OpenAI 这是在提前给那个世界占位，而且它肯定不会是唯一一家试的。
