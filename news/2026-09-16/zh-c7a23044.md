# Anthropic 把聊天和干活之间那条线删掉了

> 来源 / Source: https://clauday.com/zh/article/c7a23044-d330-4960-83e0-096b8115fdb2

Cowork 作为一个独立产品没了。9 月 16 日 Anthropic 把它塞回了 Claude 里，又变回一个东西：你打字，Claude 自己判断这是一个要回答的问题还是一件要去做的事。不用切模式，不用开第二个应用，也不用「进入 agent 界面」。公告在 https://claude.com/blog/cowork-is-now-claude ，Pro 和 Max 先上，网页、桌面、手机同步推，Team 和免费版随后，企业版任何改动前有 30 天通知。

跟着一起来的东西比合并本身更值钱。Claude Docs 和 Slides 在付费计划上进 beta，意思是一次长时间 agent 跑完之后交出来的是一份能用链接打开、能导成 PowerPoint 和 PDF 的文档或者演示稿，而不是一大段得你手动往外抄的聊天记录。Design 也搬进了对话里。Skills、连接器、历史记录跟着你走，不再绑死在你碰巧从哪个入口进来的那个界面上。

值得记一笔的是这个拆分才多新。Cowork 当初是作为独立工作区发的，因为行业共识说聊天和 agent 干活是两种产品、需要两套界面。真用了几个月之后，被删掉的恰恰是那个独立工作区。过去一个季度刚在自家聊天框旁边搭了一块独立 agent 画布的厂商，应该好好读一下这件事。

真正的新东西是那个「先问一声」的开关：你来决定 Claude 是动手前先确认，还是只在卡住的时候才来找你。整个自主权之争被压成了一个开关，把它放进面向普通用户的界面里，这个表态比 Docs 加 Slides 加起来还重。它同时意味着权限问题从「我现在在哪个应用里」变成了「我给了它多长的绳子」，后者更难想清楚，也更难收回来。
