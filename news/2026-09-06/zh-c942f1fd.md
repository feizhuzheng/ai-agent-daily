# 一个工程师的 .agents 文件夹，拿了 25 万 star

> 来源 / Source: https://clauday.com/zh/article/c942f1fd-6cd1-4416-a3f8-73282afda53e

今天 GitHub trending 第二名、单日涨 2,206 star、总量 25.4 万的仓库，是一个装满 markdown 文件的文件夹。mattpocock/skills（https://github.com/mattpocock/skills）——TypeScript 教育者 Matt Pocock，那个有 6 万订阅 newsletter 的人——把自己私人的 .agents 目录发了出来，标语是"给真工程师的 Skills"。MIT 协议，适配 Claude Code 和 Codex。

内容读起来像一年 agent 开发攒下的伤疤。/tdd 强制测试先行的循环，/code-review 跑双轴代码评审纪律，/grill-with-docs 会先"拷问"你、建好领域模型再写代码，/handoff 把对话压缩好交给下一个 agent 接盘。README 直接点名这些技能防的四种失败：偏离需求、废话太多、代码跑不通、架构腐烂。哲学写得很明白：小、可组合、可魔改——一次能读完的技能，对抗读不完的框架。

再看看榜单其他位置，这就不是一个仓库的故事了。humanlayer/skills（今天 +451）在发 design-control-loop、build-iterated-agentic-loop 这种技能，用 npx skills add 安装；openai/skills，Codex 官方技能目录，2.56 万 star；coreyhaines31 的 marketingskills——给 Claude Code 用的转化率优化、SEO、文案技能——4.7 万 star 还在涨。trending 页面悄悄变成了一个技能货架，而且正在越过工程，伸向营销，后面排着队的是所有行业。

这条供应链现在有两端。北京智源用机器把一千个 GitHub 仓库蒸馏成五千个技能（https://clauday.com/zh/article/06b1516c-06ce-4919-b755-6edc21434365）；Pocock 用亲身踩坑手写了二十个。手工这端拿到 25 万 star，是一个很实在的信号：专业知识变成可安装的文本，是这一轮的分发护城河，而目前赢的是真正疼过的人。
