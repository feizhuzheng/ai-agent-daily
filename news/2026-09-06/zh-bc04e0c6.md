# OpenAI 给自己量了个数：每 1 个人类工作日，配 3.1 个 agent 工作日

> 来源 / Source: https://clauday.com/zh/article/bc04e0c6-182c-4740-b05e-61d9ad0290aa

去年秋天 OpenAI 给自己定了个死线：2026 年 9 月之前做出"自动化研究实习生"。9 月 6 日它发文宣布死线达成——更有意思的是，把内部遥测数据一并公开了（https://openai.com/index/research-acceleration-view-inside-openai/）。所谓"实习生"，是能在人类指挥下完成定义明确的研究任务的系统，包括那些熟练研究员要花好几天的任务。路线图上的下一行才是该画圈的：完全自动化的 AI 研究员，目标 2028 年 3 月。

数字本身就是新闻。到 8 月中旬，OpenAI 研究员的中位数是每天都在用 agent，按 API 价格算每天烧掉 600 多美元的推理——90 分位的用户一天烧 7000 美元以上。8 月每个活跃实验者跑的实验数创了历史新高，是 2025 年 1 月开始统计以来最高的。压轴的比率：整个研究部门现在每投入 1 个人类工作日，就得到 3.1 个 agent 工作日的产出。每天 600 美元，按年算差不多是一份研究员薪水在和研究员并行运转——而 OpenAI 显然觉得这钱花得太值了。

递归自我改进原本是博客上吵来吵去的预测，这是第一次有前沿实验室把它当仪表盘发出来：每人每天多少美元、每人多少实验、几个 agent 工作日换一个人类工作日，全部带日期。Anthropic 的对应数据点早两天落地——11 天无人值守、60 亿 token，把费马大定理形式化了（https://clauday.com/zh/article/df158b63-7fa5-4a07-8a29-8dc577933810）。两家实验室现在都在用数字告诉你：我们的研究有多少是机器做的。

同一天，同一个网站上，OpenAI 的首席科学家发了篇文章，说没有一家实验室把对齐解决到可以全速扩张的程度（https://openai.com/index/an-alien-mind/）。油门和刹车，同日发布。这个矛盾不是失误——这就是前沿的真实状态，难得印出来给公众看一次。
