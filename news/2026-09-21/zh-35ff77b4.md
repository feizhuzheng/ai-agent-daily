# 灵感雷达: 2026-09-22

> 来源 / Source: https://clauday.com/zh/article/35ff77b4-9b6e-418b-80a0-59d9d3d0a481

今天有两件事格外突出。第一，关于 agent 基础设施的诉求不再要求「能力」，开始要求「问责」：要的是可重放的执行记录而不是一条 trace、一份关于「什么才算做完」的显式契约、一本规定 agent 何时可以自己动手的规则手册、给便宜路由器用的静默失败检测，以及一种办法——当一处改动由一个 agent 提出、另一个 agent 评审、再由一个只看了摘要的人合并时，搞清楚究竟是谁做的决定。最锋利的一句框架来自这样一个人：他指出经济账是在第二次运行时崩掉的，不是第一次——那时候你得决定要不要检查输出，而检查往往比你自己干还贵。第二，同一个窗口里有三个不同的人各自独立地要一个「坐在所有厂商之上」的 harness：一个能同时接两大 agent，一个同时跑两个、挑当天错得少的那个，还有一个能把任何新 harness 的功能都吸收进来。用户已经不再要求「一个更好的 agent」了。除此之外，最好的那些单条诉求都来自已经在脑子里把工程做完了的人——一个包含元件与到手运费的整板组装比价器、一份按你即将要读的那本书排序的汉字学习计划、一条取代按坐席收费产品的工程利润流程、一个替计算器不肯裁的分账争议做判定的裁决者，还有一套远程协助——好让儿子在帕金森让屏幕变得无法操作时，替母亲把账单付了。

这个月人人都在发的「便宜模型路由」模式，有一个没被定价的失败模式。一条便宜的意图启发式规则能拿到大部分收益，而真正贵的部分是：抓住那些便宜模型自信地答错、而你在日志里永远看不到的情况。自信的错误答案不会抛异常、不会重试、不会出现在任何错误率里——它只是安静地让产品变差。缺的那个工具是路由器的静默失败检测：在抽样上让便宜路径与昂贵路径影子并跑，给分歧打分，然后专门把「自信且错误」那一桶捞出来。这个月发出来的每一个路由产品都公布了延迟和成本数字，没有一个公布假阳性率。

他划出了一条开源 agent 栈反复越过却没意识到的线：开放权重加开放 harness 加开放操作系统，如果你没法重建每一次工具调用和每一次状态变更，那它照样可以是「你信我就完了」。缺的是可重放的执行——不是事后做取证用的 trace，而是一份完整到能把同一次会话重跑一遍、并得到同样结果的记录。「一份你能读的日志」和「一次你能复现的运行」之间的区别就是整个缺口，而开放 agent 这个圈子里没有人在卖后者。

他要的是一套通用的记录系统，而有意思的不是这个名字，是他勾勒的那个机制。你让 agent 去跟踪某样东西——他举的例子是车辆库存——它会先拉下一份契约，描述这类数据应该怎么存，然后把记录推给一个服务，由这个服务对照契约做校验。agent 不发明 schema，存储层也不信任 agent；schema 是一份被取下来的共享产物，而校验发生在 agent 之外。目前市面上每一个 agent 记忆产品做的事都跟这个相反。

生态产品雷达

agent 权限与审计层 —— 本窗口至少在六条互不相干的诉求里被提到，现在是这个栏目里持续时间最长的未满足需求。新出现的角度是端侧（本地推理砍掉的是云端风险，信任问题原封不动）、运行时可强制执行的规则手册，以及一处改动经过两个 agent 和一个人之后的归因问题。

评测作为独立产品 —— 四个人从不同方向走到了同一个地方：带显式「完成契约」的对抗性任务设计、用刻意做丑的输入做重放、给路由器做静默失败检测，以及那条论证——它不能由被评测的那一方来提供。

跨厂商 harness —— 同一个窗口里三条独立诉求，都指向所有编程 agent 之上的那一层，区别只在于它该去仲裁功能、当天的质量、还是模型本身。

决策模型 —— 现在出现在需求帖里的身份是一个组件而不是一个话题：一个给网站用户证言打可信度分的浏览器扩展，以及那条观察——真正的生意是标注好的校准数据，因为带类型的判断跑起来便宜、标起来贵。

收藏与取回 —— 这一族第十二次以上出现，这次的形态是书签墓地和目录站。收藏是免费的，取回不是；而这个品类里的每一个产品优化的都是错的那一半。

手艺与小生意工具 —— 那条稳定的矿脉：一个有人希望以「可打印的设计」而不是「可购买的产品」形式存在的电容引脚折弯治具、一个表带转表耳的适配件、一把给细软短发用的小筒径吹风梳、一个配电盘电流记录仪、一个真正密封的防氧化首饰盒。

自托管的功能对等 —— 家用服务器上的语义照片搜索、一个保住社交层的联邦式观影追踪器、有声书文件整理，以及一个因为去谷歌化而丢掉的 OCR 便利。共同的模式是：这些人是主动离开云的，然后丢掉了让那样东西好用的唯一那个功能。
