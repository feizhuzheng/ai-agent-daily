# 一万个 agent 跑了 88 小时，千禧年难题被捅穿了

> 来源 / Source: https://clauday.com/zh/article/95e286ec-891e-46df-aea8-0267afd145b7

OpenAI 说自己在七大千禧年难题上砸开了一个口子。一个未发布的模型（官方说法是"显著强于 GPT-6 Astra"）带着最多一万个 agent 跑了 88 小时，产出一份约 100 页、Lean 形式化验证过的证明：带外力的三维 Navier-Stokes 方程存在有限时间爆破。整个过程中 agent 之间发了将近 500 万条消息。Sebastien Bubeck 估算算力花了几百万美元，另一个模型又花 17 小时把结果形式化。正式开跑之前，先派了大约 100 个 agent 在 Euler 方程上热身 50 小时。

星号打在"带外力"这个词上。Clay 研究所的题面主打的是无外力方程，数学家们吵了一整天：光滑外力下的环面爆破到底算不算奖项的 option D，还是只算"很接近"。但不管算不算，这条数学路线本身有主：Diego Cordoba 和 Luis Martinez-Zoroa 花了好几年搭起来的 forced blowup 纲领。Tristan Buckmaster——他和 Levent Alpoge 沿同一条路在八月就悄悄做出了 Lean 验证的 Euler 爆破——直接放话：凭这套工作，Martinez-Zoroa 配得上菲尔兹奖。路不是 swarm 修的，swarm 只是用机器速度把它开到了头。

就算你不关心流体力学，这个框架也值得记住。上周 Anthropic 的费马大定理形式化是 1300 万行 Lean、11 天无人值守（https://clauday.com/zh/article/df158b63-7fa5-4a07-8a29-8dc577933810）；OpenAI 自己的仪表盘说研究员每人每天能换来 3.1 个 agent 工作日（https://clauday.com/zh/article/bc04e0c6-182c-4740-b05e-61d9ad0290aa）。现在一个万级 swarm 花不到一个资深研究员一年工资的算力，关掉了一个从 1934 年悬到今天的问题。Buckmaster 自己的原话：这是深蓝对卡斯帕罗夫的时刻。

这也是一个月内第四起大型 swarm 事件——前三起是 Hugging Face 被黑的复盘、collusion.wiki 论坛、DeepMind 的 swarm 作弊论文。四起事件一个共同规律：swarm 做出了真东西，周围的人类立刻开始为"到底发生了什么、功劳算谁的"打起来。这次也不例外，看姊妹篇。
